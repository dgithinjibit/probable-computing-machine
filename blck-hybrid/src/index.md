# Blockchain Hybrid Course

Fourteen ordered days through the blockchain books on this laptop and the four code courses sitting beside them: Mastering Blockchain, the Bitcoin Programming book, the Princeton crypto chapter, the Ethereum/Solidity reference, the Sui Move intro course, the Scrypto challenges, the Cairo book and starklings. Each day names the exact pages, carries a bite of the author's words, and ends at a file you can open and run.

## How this course works

Same rhythm as the other branches: **recall** the previous days at 1, 3, 7 and 21 lessons back, **read the author** at bite size, **practice** on a real local file, **check** out loud, then pass the mastery gate before the Next button moves.
