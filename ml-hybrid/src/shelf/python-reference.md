# Python reference shelf

_Drop-in references for the Python skills days (Days 1-3, 60-61) and the code you
write in `~/Desktop/ML/codes/`. These are lookup material, not reading assignments:
open one when you are stuck, close it when you are not._

| File | What it actually is | Reach for it when |
|---|---|---|
| `Python Cheatsheet.pdf` | Two-page "Essential Python Cheat Sheet" by sschaub (cheatography): data types, comparison operators, string operations. | You have forgotten a syntax detail mid-exercise and do not want to leave the terminal. |
| `Python Essential Cheatsheet.pdf` | Same class of sheet, but `pdftotext` returns no text layer - it is scanned or image-based, so it is unreadable to the tooling and to the course search. | Only as a printed page. If you want it searchable, the text has to be typed back in by hand; there is no OCR on this machine. |
| `Python Crash Course – Ole Nielsen (en).pdf` | ANU School of Mathematical Sciences lecture notes (2002) - Python taught for numerical and scientific work. | You want the maths-and-arrays framing rather than the web-app framing. Read the first ten pages; skip the rest. |
| `Python complete notes🥇.pdf` | QuantInsti, "Python Basics with illustrations from the financial markets", 290 pages, ~60,000 words, no detectable chapter headings. | You want one topic drilled with worked examples. Because the file has no chapter structure, `build_course.py` cannot slice it into days - use it as a book, not as a spine source. |

## How to use these without breaking the course rule

The spine is one ordered path. These pages are reference: you may open them at any
time, but finishing them is never what unlocks a day. If you find yourself reading
one for more than one sitting, that is a signal the day's bite was too thin - note it
in your log and move on with the day.

Do the opposite test too: after Days 60 and 61, close every file and write the five
core terms and the five-step training shape from memory. If you cannot, the cheatsheet
is the day you owe yourself, not the day after.
